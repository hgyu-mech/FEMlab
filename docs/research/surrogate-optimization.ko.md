# Kriging과 고충실도 해석을 연결하는 최적설계

## 첫 문제와 평가 기준

브래킷에서 질량을 줄이면서 변위와 응력의 허용치를 지킨다. 설계변수는 두께 $t$, 필렛 반경 $r$, 리브 폭 $w$다. 하중과 물성은 적용할 시나리오로 고정하거나 미리 정한 범위에서 평가한다. CAD 질량은 계산 비용이 충분히 작으면 직접 구한다. 응력은 구속 모서리의 특이점 영향을 피할 수 있도록 고정 평가 영역과 응력 집계 방식부터 정의하고 메시 수렴을 확인한다.

$$
\min_{x=(t,r,w)\in\mathcal{D}} m(x)=\rho V(x),\qquad
g_u(x)=\frac{|u_{\mathrm{probe}}(x)|}{u_{\lim}}-1\le0,\qquad
g_s(x)=\frac{\sigma_{\mathrm{ROI}}(x)}{\sigma_{\lim}}-1\le0.
$$

동적 성능도 설계 요구라면 첫 고유진동수 $f_1$에 하한을 두거나 질량 최소·$f_1$ 최대의 Pareto 해를 비교한다. 형상 생성 실패, 메시 실패, 솔버 미수렴과 결과 누락은 각각 상태값으로 기록한다. 성공한 해석의 물리량과 섞어 회귀시키면 실패의 뜻이 모호해진다.

| 무엇을 바꾸나 | 무엇을 최소화하거나 최대화하나 |
|---|---|
| 형상을 바꾸는 설계 최적화에서 $x$ | 제약을 만족하는 후보 중 질량을 최소화한다. |
| 대리모델 학습에서 가중치 $\theta$ | 기준 해석과 예측의 차이를 줄인다. Ridge 예시는 $n^{-1}\sum_i[(\hat y_\theta(x_i)-y_i)/s_y]^2+\lambda\lVert\theta\rVert_2^2$다. 스케일 $s_y$는 물리 기준 또는 학습 분할에서 고정한다. |
| 신경망 내부의 활성화 함수 $a(z)$ | $\tanh(z)$ 같은 비선형 변환으로 모델 표현을 정한다. Kriging은 평균과 공분산 커널을 사용한다. |
| 다음 해석점을 고르는 순차 실험에서 $x_{n+1}$ | 제약을 만족하며 설계를 개선할 기대량이나 예측 불확실성 감소량을 높인다. |

대리모델이 추정하는 목적과 제약의 결합분포를 사용할 수 있다면 다음 획득함수로 고충실도 실행 후보를 고른다. 여기서 $m_*$는 고충실도 해석으로 제약을 확인한 현재 최선의 질량이다. 질량을 직접 구할 수 있으면 $M(x)=m(x)$로 놓는다. 확인된 feasible 후보가 없으면 제약 만족 가능성 또는 기대 위반 감소 기준으로 먼저 탐색한다. [제약 Bayesian optimization](https://proceedings.mlr.press/v32/gardner14.html) · [Kriging 기반 EGO](https://doi.org/10.1023/A:1008306431147)

$$
a(x)=\mathbb{E}\left[(m_*-M(x))_+\,\mathbf{1}\{G_u(x)\le0,\ G_s(x)\le0\}\mid\mathcal{D}_n\right].
$$

## Ordinary Kriging과 Matérn Gaussian Process

Kriging을 소량의 고비용 해석을 위한 기준 후보로 사용한다. FEMlab의 기존 `RidgeSurrogate`로 단순 기준선을 만들고 같은 입력·고충실도 예산으로 비교한다. Ordinary Kriging은 일정하지만 미지인 평균을 데이터에서 추정하고, 공분산으로 가까운 설계의 정보가 얼마나 연결되는지 정한다. $K$를 학습 관측치의 공분산 행렬, $k_*$를 새 설계와 학습 설계 사이의 공분산 벡터로 놓으면, 고정 공분산 파라미터에서 일반화최소제곱 평균과 예측은 다음과 같다. 실제 구현은 Cholesky 분해 등으로 선형계를 푼다. [컴퓨터 실험의 Kriging 원 논문](https://doi.org/10.1214/ss/1177012413) · [FEMlab의 Ridge 기준선](../../femlab/ml.py)

$$
\hat\beta=\frac{\mathbf{1}^{\mathsf{T}}K^{-1}y}{\mathbf{1}^{\mathsf{T}}K^{-1}\mathbf{1}},\qquad
\hat y(x_*)=\hat\beta+k_*^{\mathsf{T}}K^{-1}(y-\hat\beta\mathbf{1}).
$$

Matérn은 이 모델에서 사용할 수 있는 공분산 커널의 종류다. 따라서 상수 평균을 추정하는 Matérn GP와 Ordinary Kriging은 위 설정에서 같은 예측 구조를 공유한다. 고정 영평균, 복잡한 추세, 커널 파라미터 불확실성 적분처럼 설정을 바꾸면 예측과 불확실성이 달라질 수 있다. 예를 들어 Matérn $\nu=3/2$에서 $k(x,x')=\sigma_f^2(1+\sqrt3 d)\exp(-\sqrt3d)$이고 $d$는 스케일을 맞춘 설계 공간의 거리다. 데이터가 적을 때는 한 공통 길이척도로 시작하고 변수별 길이척도는 그룹 검증으로 판별한다. [공분산 함수와 GP 원문](https://gaussianprocess.org/gpml/chapters/)

중복 입력의 수치 안정화를 위한 작은 diagonal jitter와 관측 변동을 모델링하는 nugget은 목적이 다르다. 같은 형상·해석조건의 반복은 관측 변동 추정에 쓰고, 독립 설계 커버리지는 서로 다른 물리 케이스를 확보해 늘린다. 메시·시간 간격·모델 충실도에 따른 체계적 차이는 해석 조건에 보존한다. 동일 물리량으로 저충실도와 고충실도가 짝지어질 때 $y_H(x)\approx\rho' y_L(x)+\delta(x)$ 형태로 차이를 학습할 수 있다. 짝지은 데이터로 저충실도의 순위와 편향부터 보고 고충실도만 사용한 모델과 비교한다. [GP 검증 진단](https://doi.org/10.1198/TECH.2009.08019) · [다중 충실도 원 논문](https://doi.org/10.1093/biomet/87.1.1)

## 샘플을 10개 늘렸을 때 LOOCV가 오르는 사례

LOOCV는 매번 관측 하나를 빼고 다시 학습한 예측의 오차를 모은다. 샘플을 추가하면 검증하는 위치의 분포와 각 fold의 학습 자료가 함께 바뀐다.

$$
\operatorname{RMSE}_{\mathrm{LOO}}(D_n)=
\sqrt{\frac1n\sum_{i=1}^n (y_i-\hat f_{D_n\setminus\{i\}}(x_i))^2}.
$$

설계영역의 낮은 구간에서 참값은 0, 높은 구간에서 참값은 1이라고 한다. 모델은 학습 데이터의 평균을 항상 출력한다. 낮은 구간의 서로 다른 설계 10개로 시작해 높은 구간의 설계 10개를 추가한다. 별도의 고정 테스트는 두 영역을 동일 비중으로 보며 두 설계는 학습 설계와 겹치지 않는다.

| 학습 표본 | LOOCV RMSE | 동일한 테스트 RMSE |
|---|---:|---:|
| 10개 · 참값 0만 관측 | 0.000000 | 0.707107 |
| 20개 · 낮은 구간 10개와 높은 구간 10개 | 0.526316 | 0.500000 |

20개에서 0을 빼면 예측은 $10/19$, 1을 빼면 $9/19$다. 각 오차의 절댓값이 $10/19$이므로 LOOCV RMSE도 같다. 처음 10개의 LOOCV에서 빠진 높은 구간을 평가로 포함하자 점수가 올랐고, 고정 테스트에서의 오차는 내려갔다. 이는 표본 구성의 효과를 보여주는 결정론적 예제다.

```python
from math import sqrt
from statistics import fmean


def rmse(errors):
    return sqrt(fmean(error**2 for error in errors))


initial = [0.0] * 10
held_out = [0.0, 1.0]
for train in (initial, initial + [1.0] * 10):
    loo = rmse(
        actual - fmean(train[:i] + train[i + 1 :])
        for i, actual in enumerate(train)
    )
    fixed = rmse(actual - fmean(train) for actual in held_out)
    print(f"n={len(train):2d}  LOOCV={loo:.6f}  fixed={fixed:.6f}")
```

초기 독립 설계가 적으면 LOOCV를 탐색 진단으로 쓸 수 있다. 시간을 자른 행, 메시를 조금 바꾼 관측, 동일 설계의 고·저충실도처럼 서로 연결된 행은 물리 케이스 또는 형상·하중군 단위로 한 fold에 넣는다. 데이터 정규화, 커널과 변수 선택, 신뢰 기준의 튜닝은 내부 그룹 fold에서 하고 바깥 그룹으로 평가한다. 순차 실험 학습곡선은 같은 검증 세트에서 반복해 비교한다. 별도의 최종 검증 그룹은 모델과 선별 규칙을 확정한 뒤에만 연다. 독립 그룹이 적으면 그룹별 오차와 실제 표본 수를 보여주고 적용 범위를 제한한다. [그룹·블록 CV](https://doi.org/10.1111/ecog.02881) · [Nested CV 연구](https://doi.org/10.1186/1471-2105-7-91) · [모델 선택의 과적합](https://jmlr.csail.mit.edu/papers/v11/cawley10a.html)

## 대리모델을 쓸 구간과 고충실도 전환

초기 DOE에는 시드를 기록한 Latin hypercube와 경계·대표 하중 조건을 넣는다. 다음 배치를 10개로 정하면 설계 공간의 빈 구간, 허용치를 넘나드는 제약 경계, 현재 최적 후보 주변의 불확실한 지점에 배분한다. 배치 크기와 갱신 횟수는 계산 예산 안에서 결정한다. 최종 평가 그룹은 순차 샘플 후보에서 제외한다. [LHS 원 논문](https://doi.org/10.1080/00401706.1979.10489755)

1. 적용할 형상·하중군, 설계변수 한계, 학습점에 대한 정규화 거리 등으로 예측 적용 범위를 정의한다. 관측한 접촉 상태나 재료 거동이 바뀌는 영역은 별도 검사한다.
2. 제약 예측의 상측 기준 $\mu_{g_j}+k_j\sigma_{g_j}\le0$으로 후보를 선별할 수 있다. $k_j$와 거리 기준은 내부 검증의 실제 포함률과 경계에서의 오판으로 정하고, 해당 값은 예측의 선별 규칙으로 기록한다. 제약별 포함률을 공동 만족 확률로 읽으려면 공동 오차 관측이나 별도 보정이 필요하다.
3. 적용 범위 밖, 오차 검증이 부족한 곳, 예측 제약 한계에 걸치는 곳은 고충실도 솔버로 확인한다. 최종 후보는 예측이 여유로워도 실제 해석으로 다시 풀고 필수 제약과 수렴을 확인한다. 고충실도 결과가 재현되지 않는 영역에서는 적합했던 모델이나 신뢰영역의 범위를 갱신한다. [신뢰영역 기반 모델 관리](https://www.cs.wm.edu/~va/research/adlt.pdf)

같은 고충실도 호출 예산으로 **고정 DOE + Ridge**, **고정 DOE + Kriging**, **초기 DOE + 적응형 Kriging**을 비교한다. 각 비교군에 같은 초기 고충실도 설계를 주고, 적응 구간의 계산을 포함해 총 호출 수를 맞춘다. 실패한 실행, 재시도와 최종 검증도 비용에 포함한다.

**연구 가설**은 적응형 Kriging에 고충실도 전환 규칙을 추가하면 같은 예산에서 더 가벼우면서 실제 제약을 만족하는 설계를 찾을 수 있다는 것이다. 적응형 Kriging에 해당 규칙을 적용한 군을 별도로 추가하고 전체 군에서 최종 후보의 고충실도 검증을 공통으로 시행한다. 동일한 테스트에서 오차와 경험적 구간 포함률, 제약 위반을 통과시킨 건수와 전체 통과 수, 실제 feasible 후보 검출률을 함께 남긴다. 실제로 확인한 최선의 feasible 질량과 거기에 도달하는 비용을 방법별로 비교한다.

실험 기록에는 목표·제약의 단위·허용오차, seed, 형상과 하중군 ID, 메시·시간 간격, 솔버 리비전, 수렴 여부, 실행 비용, 참고한 논문의 식·가정·검증 기준을 남긴다. 이번 문서에서 실행으로 확인할 수 있는 결과는 위의 LOOCV 예제다. 브래킷·대리모델·샘플 선택 비교는 후속 실험 계획이다.
